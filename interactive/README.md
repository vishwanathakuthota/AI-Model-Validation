# DrPinnacle AI Learning Experience — Episodes 01–20

## Offline instructions
1. Extract this ZIP completely.
2. Open `index.html` in Chrome, Safari, Edge or Firefox.
3. Choose any episode, switch CXO / Beginner / Technical modes, move sliders and complete the knowledge check.
4. The HTML, CSS and JavaScript are local. No server, internet, external libraries, API keys, fonts or CDNs required.

## Design
Executive Intelligence + AI Research Studio + Visual Discovery. Responsive, accessible labeled controls and local-only quiz score storage.

## Scope and limitations
20 standalone HTML lessons share `assets/style.css` and `assets/app.js`. Each lesson has a distinct interactive experiment, three audience perspectives, a visual analogy, an equation and a knowledge check. The synthetic experiments illustrate the underlying concept; they are not production evaluations, formal statistical guarantees or real-world datasets. Episode 01 fits an actual least-squares linear model in browser to six synthetic observations. Other episodes use transparent pedagogical calculations, including some deliberately simplified illustrative curves. Each episode currently has one scored quiz question; the package is a working interactive foundation rather than a complete academic assessment system.
